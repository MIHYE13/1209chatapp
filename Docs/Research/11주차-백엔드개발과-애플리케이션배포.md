## 1. 복잡한 AI 워크플로

참고자료는 다음과 같은 다단계 흐름을 예로 듭니다.

```text
학생 데이터 정리
→ 학생 학습 분석
→ 피드백 생성
→ 발송
```

복잡한 작업을 단순 함수 연결만으로 구성하면 중간 출력 형식이 잘못되거나 일부 단계 실패 후 복구하기 어렵다고 설명합니다.

### LangChain과 LangGraph

- LangChain: LLM 기반 애플리케이션 개발을 돕는 프레임워크
- LangGraph: 복잡한 생성형 AI 워크플로를 상태와 흐름으로 구성하는 프레임워크

LangGraph의 핵심 요소:

| 요소 | 역할 | 학생 피드백 예시 |
|---|---|---|
| State | 작업에 필요한 데이터 보관 | 학생 답변, 피드백 상태 |
| Node | 실제 작업을 수행하는 함수 | 질문 분류, 피드백 생성 |
| Edge | 다음 작업 연결 | 분석 후 피드백 초안으로 이동 |

### 현재 프로젝트 적용 판단

초기 MVP는 워크플로가 짧으므로 LangChain·LangGraph를 도입하지 않습니다. 다음 조건이 생기면 도입을 재검토합니다.

- 질문 분류, 의견 분석, 개인 피드백과 모둠 피드백이 독립 단계로 늘어남
- 중간 결과를 저장하고 실패한 단계부터 재실행해야 함
- 교사 승인, 학생 공개와 발송 흐름을 상태 기계로 관리해야 함

## 2. 프론트엔드와 백엔드

자료는 웹을 사용자, 프론트엔드, 백엔드의 상호작용으로 설명합니다.

### 백엔드가 담당할 기능

- 회원가입과 로그인
- 이전 기록 조회
- 새로운 기록 저장
- 외부 API 호출
- 데이터베이스 연결

### 현재 프로젝트 적용

- 프론트엔드: 학생·교사 화면, 입력 검증, 실시간 상태 표시
- 백엔드: 활동 코드 로그인, 권한, 타이머, WebSocket, 파일, OpenAI API, SQLite
- 브라우저는 API 키와 데이터베이스 관리자 권한을 보유하지 않음

## 4. 백엔드 프레임워크

FastAPI는 Python 기반 백엔드 프레임워크로 소개됩니다. Python 기반 AI 라이브러리와 연결하기 쉽다는 점을 장점으로 설명합니다.

### 현재 프로젝트 적용

- FastAPI 사용
- WebSocket 실시간 채팅
- SQLite 로컬 데이터 저장
- OpenAI Python SDK 사용
- 프론트엔드 정적 파일 제공

## 5. Skill과 MCP

참고자료는 재사용할 작업 지침을 Skill로 패키징하고, 필요할 경우 MCP를 연결하는 흐름을 소개합니다.

### 현재 프로젝트 적용 판단

- 초기 MVP에는 별도의 업로드 Skill이나 외부 MCP를 추가하지 않습니다.
- 반복되는 탐구보고서·슬라이드 생성 규칙이 안정된 뒤 별도 Skill로 분리할 수 있습니다.
- 외부 MCP 연결은 인증과 학생 데이터 전송 범위를 검토한 뒤 진행합니다.

## 6. 환경변수와 비밀정보

참고자료는 `.env`에 인증키 등 민감한 변수를 저장하고 배포 플랫폼에도 환경변수를 설정하는 과정을 다룹니다.

### 현재 프로젝트 보안 원칙

- 실제 `.env.local`은 Git에서 제외합니다.
- `.env.example`에는 변수 이름과 안전한 자리표시자만 둡니다.
- 비밀키는 프론트엔드 코드에 포함하지 않습니다.
- 운영 환경에서는 배포 플랫폼 비밀 설정을 사용합니다.
- 이미 노출된 키는 파일에서 삭제하는 것만으로 충분하지 않으며 폐기·교체해야 합니다.

> 참고자료 중 `.env.example`을 `.env`로 바꾼 뒤 Git을 시작한다는 표현은 현재 프로젝트에 적용하지 않습니다. 실제 비밀값이 있는 환경파일은 Git 초기화 전후와 관계없이 항상 추적에서 제외합니다.

## 7. 배포 구조

참고자료가 제시한 예시 배포 방식:

- 프론트엔드: GitHub 저장소와 Netlify 연결
- 백엔드: GitHub 저장소와 Google Cloud Run 연결
- 데이터베이스: Firebase Firestore
- 배포 환경변수: Netlify와 Cloud Run 설정에서 주입

### Google Cloud 예시 설정

- Cloud Run Admin API 활성화
- 저장소 연결
- Cloud Build 설정
- 서비스 계정과 Firestore 권한 연결
- 환경변수 설정
- 인스턴스 최대 개수 설정

### 현재 프로젝트 적용 판단

- 1시간 MVP는 로컬 실행과 같은 와이파이 시연을 우선합니다.
- 외부 공개 배포는 학생 데이터, 인증, HTTPS, CORS, 파일 저장과 보안 검토 후 진행합니다.
- Cloud Run의 공개 접근을 자동으로 허용하지 않습니다.
- 운영 배포 시 프론트엔드와 백엔드를 별도 저장소로 나눌지는 배포 방식과 팀 운영을 보고 결정합니다.
- 비용과 서비스 사양은 배포 시점의 공식 문서를 다시 확인합니다.
