# 활동 타이머 요구사항

## 교사 기능

- 교사는 활동별 채팅 가능 시간을 설정할 수 있어야 합니다.
- 교사는 활동 시작 전 설정한 시간과 종료 예정 시각을 확인할 수 있어야 합니다.
- 교사는 모든 모둠의 남은 시간과 종료 상태를 확인할 수 있어야 합니다.

## 학생 기능

- 학생은 모둠 활동 화면에서 남은 시간을 확인할 수 있어야 합니다.
- 종료가 가까워지면 학생이 이해할 수 있는 사전 알림을 받아야 합니다.
- 종료 시점에는 채팅이 멈춘 이유와 현재 가능한 행동을 안내받아야 합니다.

## 서버 요구사항

- 활동 시작·종료 판정은 서버 시간을 기준으로 해야 합니다.
- 종료 후 새 학생 메시지를 저장하거나 다른 학생에게 전파해서는 안 됩니다.
- 종료 후 새 AI 채팅 요청을 실행해서는 안 됩니다.
- 종료 후 시작된 파일 업로드를 허용해서는 안 됩니다.
- 재접속한 기기에는 서버에 저장된 정확한 종료 상태와 시간을 전달해야 합니다.
- 여러 기기에서 종료 상태가 일관되게 동기화되어야 합니다.

## 오류·경계 상황

- 종료 시각과 메시지 전송이 겹칠 경우 서버가 수락 여부를 최종 결정해야 합니다.
- 연결이 끊긴 상태에서 작성한 메시지를 종료 후 자동 전송해서는 안 됩니다.
- 학생 기기의 시계를 변경해도 활동 시간을 우회할 수 없어야 합니다.
- 중복 종료 이벤트가 발생해도 메시지와 기록 상태가 손상되지 않아야 합니다.

## 미확정 요구사항

- 종료 후 채팅·작업 기록의 열람 범위
- 종료 후 작업 기록과 결과물의 수정·제출 범위
- 교사의 시간 연장, 일시정지와 재개 권한
- 사전 알림 시점
- 전송 중인 파일과 AI 응답의 종료 처리
