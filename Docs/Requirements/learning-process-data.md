# 학습 과정 데이터 요구사항

## 학생 질문 데이터

- 학생 질문을 작성자, 시각, 모둠과 탐구 단계에 연결해 기록해야 합니다.
- 질문이 나온 채팅 메시지 또는 자료로 돌아갈 수 있어야 합니다.
- 질문의 상태를 미해결, 논의 중, 해결 또는 보류 등으로 관리할 수 있어야 합니다.
- AI가 질문으로 분류한 경우 학생 또는 교사가 확인할 수 있어야 합니다.

## 의견 수렴 과정 데이터

- 학생이 제시한 의견과 근거를 기록할 수 있어야 합니다.
- 의견의 수정, 결합, 선택과 합의 과정을 시간 순서로 남길 수 있어야 합니다.
- 모둠 의견과 학급 전체 의견을 구분해야 합니다.
- 최종 선택 결과뿐 아니라 어떤 의견들이 검토되었는지 확인할 수 있어야 합니다.

## 역할·수행 데이터

- 학생별 이끄미, 기록이, 나누미, 지키미 역할을 기록해야 합니다.
- 역할 배정과 변경 시각을 기록해야 합니다.
- 역할별 할 일, 진행 상태와 수행 과정을 연결해야 합니다.
- 모둠원 부족에 따른 겸임 또는 미배정 상태를 표현할 수 있어야 합니다.

## 교사 확인

- 교사는 담당 활동의 모둠별 질문, 의견 수렴과 역할 수행 과정을 확인할 수 있어야 합니다.
- 교사는 채팅 원문과 구조화된 기록을 오가며 근거를 확인할 수 있어야 합니다.
- 학급 전체 요약과 개별 모둠 상세를 구분해 볼 수 있어야 합니다.
- AI 분석 결과는 사실이나 평가가 아니라 보조 정보임을 표시해야 합니다.

## 개인정보·공정성

- 학습 과정 데이터는 학생 개인정보로 취급해야 합니다.
- 메시지 수나 발언량만으로 참여도·성취도를 자동 판정해서는 안 됩니다.
- AI가 학생의 능력, 태도 또는 성격을 단정해서는 안 됩니다.
- 보관 기간, 삭제 권한과 평가 활용 여부를 학생·교사에게 안내해야 합니다.

## 미확정 요구사항

- 성적 또는 공식 평가 활용 여부
- 전체 학생 의견 수렴 방식
- 학생에게 보여줄 개인·모둠·학급 데이터 범위
- 보관 기간과 내보내기 형식
- 교사용 분석 화면과 지표

## 확정된 활용 목적

- 축적된 데이터는 학생 개인과 모둠에 과정 중심 피드백을 제공하는 데 사용합니다.
- 피드백은 구체적인 활동 기록과 연결되어야 하며 성적 산출과 분리합니다.
