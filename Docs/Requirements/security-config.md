# 환경설정 및 비밀정보 요구사항

## 확정 요구사항

- 실제 환경변수 파일은 Git 추적 대상에서 제외해야 합니다.
- API 키, 토큰과 인증 파일은 GitHub에 업로드해서는 안 됩니다.
- 서버용 비밀정보는 프론트엔드 번들 또는 브라우저 저장소에 포함해서는 안 됩니다.
- 운영 비밀정보는 배포 플랫폼의 환경변수 또는 비밀 관리 기능을 사용해야 합니다.
- 예시 환경파일에는 변수 이름, 목적과 안전한 자리표시자만 포함해야 합니다.
- 애플리케이션 로그와 오류 응답에서 비밀정보를 가려야 합니다.
- 저장소와 배포 전에 비밀정보 포함 여부를 검사하는 절차를 마련해야 합니다.
- 첫 Cloud Run 교실 시연 배포는 공개 HTTPS 접근을 허용하되 최대 인스턴스를 1개로 제한해야 합니다.
- 공개 시연 배포에는 기본 교사 코드 `teacher-demo`를 사용하지 않아야 합니다.
- 실제 학생 데이터와 OpenAI 호출은 상태 API 검증이 끝난 뒤 별도 단계에서 활성화해야 합니다.
- `DEPLOYMENT_MODE=health-only`에서는 `/`와 `/api/health` 외의 HTTP 요청과 모든 WebSocket 연결을 차단해야 합니다.

## 미확정 요구사항

- 로컬·시험·운영 환경 분리 방식
- 장기 운영용 비밀 관리 서비스와 키 교체 정책
- 비밀정보 검사 도구와 CI 적용 방식
- 키 교체 주기와 사고 대응 절차
