# 학생 등록 및 로그인 요구사항

## 등록 화면

- 학생은 학급을 입력하거나 선택할 수 있어야 합니다.
- 학생은 이름을 입력해야 합니다.
- 학생은 1모둠부터 6모둠 중 하나를 선택해야 합니다.
- 필수 정보의 누락과 잘못된 입력을 학생이 이해할 수 있는 문장으로 안내해야 합니다.
- 등록 완료 전 입력 내용을 다시 확인할 수 있어야 합니다.

## 로그인과 모둠 연결

- 학생은 교사가 안내한 학급 공통 활동 코드, 등록된 이름과 1~6 중 모둠 번호로 로그인해야 합니다.
- 서버는 활동 코드가 현재 유효하고 해당 이름·모둠 조합이 활동 명단에 등록되어 있는지 확인해야 합니다.
- 등록된 학생은 로그인 후 자신의 활동과 모둠방으로 이동해야 합니다.
- 로그인 상태를 새로고침과 일시적인 연결 끊김 이후에도 안전하게 복구해야 합니다.
- 학생은 다른 모둠의 채팅과 파일에 접근할 수 없어야 합니다.
- 모둠 값은 서버에서도 1~6 범위인지 검증해야 합니다.
- 화면에서 모둠 값을 바꾸는 것만으로 다른 모둠에 접근할 수 없어야 합니다.
- 입력된 모둠 번호만 신뢰하지 않고 서버에 등록된 배정 정보로 방 접근 권한을 결정해야 합니다.

## 개인정보 및 보안

- 학급과 학생 이름은 아동 개인정보로 취급해야 합니다.
- 필요한 최소 기간만 저장하고 보관·삭제 정책을 학생과 교사에게 안내해야 합니다.
- 로그인 실패 응답으로 특정 학생의 등록 여부를 과도하게 노출해서는 안 됩니다.
- 반복된 로그인 실패를 제한해야 합니다.
- 활동 코드는 활동 시작·종료 상태에 따라 활성화하거나 만료할 수 있어야 합니다.
- 세션과 모둠 권한은 백엔드에서 검증해야 합니다.
- 교사는 담당 학급과 활동에 속한 학생만 관리할 수 있어야 합니다.

## 미확정 요구사항

- 같은 모둠 안의 동명이인 예외 처리
- 교사 승인 또는 사전 명단 사용 여부
- 등록 정보 수정·삭제와 계정 복구
- 학급과 활동의 연결 방식
