# 핵심 사용자 흐름 요구사항

## 교사 흐름

1. 교사는 과학 탐구 활동을 만듭니다.
2. 주제, 탐구 단계와 학생이 수행할 일을 제시합니다.
3. 활동에 모둠을 구성하거나 모둠방 입장 정보를 발급합니다.
4. 모든 모둠방의 채팅, AI 응답과 공유 자료를 실시간으로 확인합니다.
5. 모둠이 공유한 결과물을 확인합니다.

## 학생 흐름

1. 학생은 학급, 이름과 1~6 중 소속 모둠을 등록하고 로그인합니다.
2. 학생 4명 이하는 각자의 태블릿으로 지정된 모둠방에 입장합니다.
3. 같은 모둠의 메시지를 실시간으로 주고받습니다.
4. 작업 내용과 현재 진행 흐름을 모둠원과 공유합니다.
5. 생성형 AI 보조교사의 도움을 받아 역할, 해야 할 일과 탐구 진행 방향을 구조화합니다.
6. 채팅에서 링크와 파일을 공유하고 탐구 자료로 모읍니다.
7. 자료와 결정사항을 모아 결과물을 작성합니다.
8. 모둠원이 결과물을 확인하고 교사 또는 학급에 공유합니다.

## 초기 운영 조건

- 주 사용 장소는 교실입니다.
- 학생 기기는 같은 학교 와이파이에 연결됩니다.
- 모둠당 학생 4명을 초기 기준으로 삼습니다.
- 모둠방은 서로 분리되어야 합니다.
- 학생 4명의 채팅과 AI 도우미 응답은 같은 모둠원에게 실시간으로 보여야 합니다.

## 미확정 요구사항

- 학생과 교사의 인증 방식
- 모둠 생성과 입장 방식
- 교사의 실시간 열람·개입 범위
- 결과물의 형식과 공유 범위
- 수업 후 이어하기와 수정 허용 여부
