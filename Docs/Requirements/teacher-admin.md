# 교사 관리자 요구사항

## 확정 요구사항

- 교사는 자신이 만든 또는 담당하는 활동의 관리자여야 합니다.
- 교사는 해당 활동에 속한 모든 모둠과 접속 상태를 확인할 수 있어야 합니다.
- 교사는 모든 모둠방의 학생 메시지와 AI 응답을 실시간으로 확인할 수 있어야 합니다.
- 교사는 채팅에서 공유된 링크와 첨부 파일을 확인할 수 있어야 합니다.
- 교사는 모둠의 현재 작업 단계, 할 일과 결정사항을 확인할 수 있어야 합니다.
- 학생은 채팅 시작 전에 교사가 활동 내용을 확인할 수 있음을 알 수 있어야 합니다.
- 학생은 다른 모둠의 채팅이나 자료를 열람할 수 없어야 합니다.
- 교사는 자신이 담당하지 않는 활동의 학생 자료를 기본적으로 열람할 수 없어야 합니다.
- 모든 권한 검사는 화면 표시뿐 아니라 백엔드에서도 수행해야 합니다.
- 교사는 모둠 채팅에 일반 메시지를 보내지 않아야 합니다.
- 교사는 학생 대신 AI 제안을 반영하거나 탐구 결과를 확정하지 않아야 합니다.
- 교사는 활동별 채팅 가능 시간을 설정하고 모든 모둠의 남은 시간을 확인할 수 있어야 합니다.
- 교사는 담당 활동에서 축적된 학생 질문, 의견 수렴 과정, 역할 분담과 수행 기록을 확인할 수 있어야 합니다.

## 확정된 역할 경계

- 교사는 활동과 모둠방의 운영 관리자입니다.
- 교사는 학생 학습 과정에는 직접 개입하지 않는 관찰자입니다.
- 관리 기능과 채팅 참여 기능은 별도 권한으로 분리하며, 교사에게 일반 채팅 참여 권한을 부여하지 않습니다.

## 교사용 화면 후보

- 전체 모둠의 현재 단계와 접속 인원
- 모둠별 최근 메시지와 마지막 활동 시각
- AI가 감지한 막힘, 미결정 사항 또는 도움 요청
- 모둠방 상세 채팅과 공유 자료
- 모둠 결과물과 제출 상태

화면 후보의 우선순위는 후속 인터뷰에서 결정합니다.

## 미확정 요구사항

- 메시지·파일 숨김, 삭제와 복구 권한
- AI 개입 수준을 교사가 조절하는 기능
- 피드백과 평가 기능
- 채팅 기록 보관·다운로드·삭제 정책
