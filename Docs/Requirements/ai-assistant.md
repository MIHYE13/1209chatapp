# 생성형 AI 보조교사 요구사항

## 확정 요구사항

- 각 모둠방에는 생성형 AI 보조교사가 참여해야 합니다.
- AI는 교사가 제시한 주제, 목표와 활동 단계를 고려해야 합니다.
- AI는 모둠의 채팅, 현재 단계, 역할, 할 일과 공유 자료 중 허용된 맥락을 고려해야 합니다.
- AI 답변은 학생 메시지와 시각적으로 명확히 구분되어야 합니다.
- AI는 진행 방향, 다음 행동과 확인할 질문을 학생 눈높이에 맞게 제시해야 합니다.
- AI가 만든 내용은 자동으로 확정하지 않고 학생에게 반영 여부를 확인해야 합니다.
- 학생은 AI 제안을 수락, 수정, 다시 요청 또는 무시할 수 있어야 합니다.
- AI가 확실하지 않은 내용은 확실한 사실처럼 표현하지 않아야 합니다.
- 근거가 필요한 답변은 공유 자료 또는 확인 가능한 출처와 연결해야 합니다.

## 토큰·호출 효율 요구사항

- OpenAI API 호출은 백엔드에서만 수행해야 합니다.
- 학생 메시지마다 자동 호출해서는 안 됩니다.
- 전체 채팅 대신 학생이 확정한 작업 기록, 누적 요약과 최근 관련 대화만 전달해야 합니다.
- 입력 문맥과 출력 길이에 서버 측 상한을 둬야 합니다.
- 중복 요청을 방지하고 활동·모둠별 사용량을 측정해야 합니다.
- AI 호출 실패가 학생 간 실시간 채팅을 방해해서는 안 됩니다.

## 역할 후보

- 모둠 대화에서 결정된 내용과 남은 질문 정리
- 교사가 제시한 워크플로에 따른 현재 단계 안내
- 역할과 할 일의 누락 또는 편중 알림
- 탐구 질문을 관찰·측정 가능한 형태로 구체화하도록 질문
- 공유 자료의 관련성, 출처와 근거 확인 유도
- 보고서와 발표자료에 필요한 내용의 누락 점검
- 막힌 모둠에 작은 다음 행동 제안

역할 후보의 자동 실행 여부는 후속 인터뷰에서 결정합니다.

## 금지 또는 제한할 행동 초안

- 학생 대신 완성된 탐구 결과를 제출 가능한 형태로 확정하기
- 근거 없이 실험 결과나 출처를 만들어내기
- 학생을 평가·비난하거나 모둠원 사이의 서열을 정하기
- 불필요한 개인정보를 요구하거나 반복해 노출하기
- 교사가 정한 학습 목표와 안전 규칙을 우회하도록 안내하기

## 미확정 요구사항

- 호출 방식: 학생 요청, 멘션, 단계 전환 또는 자동 개입
- AI가 참고할 최근 대화 범위와 장기 요약 방식
- 활동별 교사 설정과 AI 일시 중지 기능
- 답변 길이, 빈도와 비용 제한
- 안전 필터, 오류 신고와 교사 검토 흐름
