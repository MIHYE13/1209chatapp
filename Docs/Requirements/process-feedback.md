# 과정 중심 피드백 요구사항

## 피드백 유형

### 학생 개인 피드백

- 학생이 맡은 역할과 수행 과정에 근거해야 합니다.
- 질문, 의견, 근거, 협력과 도움 요청 사례를 연결할 수 있어야 합니다.
- 학생 본인에게만 공개할 정보와 모둠에 공개할 정보를 구분해야 합니다.

### 모둠 피드백

- 역할 분담, 의견 수렴, 합의와 결과물 형성 과정을 다뤄야 합니다.
- 특정 학생을 공개적으로 비교하거나 순위를 매겨서는 안 됩니다.
- 모둠이 다음 활동에서 시도할 구체적인 개선 행동을 포함해야 합니다.

## 근거와 투명성

- 피드백은 관련 질문, 메시지, 역할 기록 또는 작업 과정으로 연결될 수 있어야 합니다.
- AI가 작성한 초안인지 교사가 작성·확정한 피드백인지 표시해야 합니다.
- 근거가 부족한 경우 단정적인 피드백을 생성해서는 안 됩니다.
- 학생이 사실과 다른 피드백을 교사에게 알릴 수 있는 방법을 마련해야 합니다.

## 금지 사항

- 메시지 수와 글자 수만으로 참여도 평가
- 학생 간 순위 또는 낙인 표시
- AI를 이용한 성격·능력·정서 상태 단정
- 근거가 없는 칭찬 또는 비판
- 개인 피드백을 다른 학생에게 기본 공개

## 미확정 요구사항

- 피드백 작성·확정 주체
- 제공 시점과 빈도
- 학생의 피드백 확인 및 성찰 응답
- 교사의 수정·승인 화면
- 보관·삭제와 내보내기 형식
