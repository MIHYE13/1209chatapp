# 채팅방 링크·파일 공유 요구사항

## 확정 요구사항

- 학생은 모둠 채팅에서 링크를 공유할 수 있어야 합니다.
- 학생은 모둠 채팅에 파일을 첨부할 수 있어야 합니다.
- 링크와 파일이 공유되면 같은 모둠원의 화면에 실시간으로 표시되어야 합니다.
- 첨부 자료에는 공유한 사람과 공유 시각이 표시되어야 합니다.
- 허용된 모둠원과 교사만 첨부 자료를 열 수 있어야 합니다.
- 공유된 자료를 탐구 자료 모음으로 옮기거나 연결할 수 있어야 합니다.
- 학생이 삭제한 자료를 다른 결과물에서 사용 중이라면 영향을 먼저 알려야 합니다.

## 안전·품질 요구사항

- 링크는 외부 사이트임을 명확히 표시해야 합니다.
- 위험하거나 지원하지 않는 URL 형식을 거부해야 합니다.
- 파일명, MIME 형식과 실제 파일 내용을 신뢰하지 않고 서버에서 검증해야 합니다.
- 실행 파일과 스크립트 등 위험한 파일 형식은 허용하지 않아야 합니다.
- 업로드 진행, 실패, 재시도와 용량 초과 상태를 학생이 이해할 수 있게 안내해야 합니다.
- 다른 모둠의 링크·파일 접근을 서버에서 차단해야 합니다.

## 미확정 요구사항

- 허용할 문서·이미지·동영상 형식
- 파일당 및 모둠당 저장 용량
- 미리보기 생성 범위
- 보관 기간, 삭제와 복구 정책
- 악성 파일 검사 서비스와 유해 링크 검사 방식
