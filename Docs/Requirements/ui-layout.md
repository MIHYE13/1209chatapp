# 학생용 기본 화면 요구사항

## 확정 요구사항

- 기본 모둠 활동 화면은 왼쪽, 중앙, 오른쪽의 3분할 구조여야 합니다.
- 중앙 영역에는 모둠 실시간 채팅방이 표시되어야 합니다.
- 중앙 채팅에는 학생 메시지, AI 보조교사 응답, 링크와 파일 첨부가 함께 표시되어야 합니다.
- 학생은 채팅 화면을 떠나지 않고 양쪽 영역의 작업 정보를 확인할 수 있어야 합니다.
- 세 영역은 제목과 역할이 명확히 구분되어야 합니다.
- 새 메시지, 업로드와 연결 상태가 중앙 영역에서 이해하기 쉽게 표시되어야 합니다.
- 교사가 설정한 남은 시간과 채팅 가능 상태를 중앙 영역에서 명확히 확인할 수 있어야 합니다.

## 영역별 역할

### 왼쪽: 교사 관리 학습 안내

- 교사가 설정한 탐구 주제, 학습 목표, 활동 단계, 할 일과 안내 자료를 표시해야 합니다.
- 학생은 교사가 관리하는 원본 정보를 임의로 수정할 수 없어야 합니다.
- 교사가 내용을 변경하면 학생이 변경 사실을 알 수 있어야 합니다.

### 중앙: 실시간 모둠 채팅

- 학생과 AI 보조교사의 메시지를 시간 순서대로 실시간 표시해야 합니다.
- 새 메시지가 자연스럽게 이어지는 대화 흐름을 보여줘야 합니다.
- 링크, 파일, 전송 상태와 발화자를 명확히 구분해야 합니다.

### 오른쪽: 모둠 작업 기록

- 채팅 과정에서 나온 역할, 할 일, 결정, 자료와 중간 결과를 구조화해 표시해야 합니다.
- 항목이 생성·수정된 시점과 작성 주체를 확인할 수 있어야 합니다.
- 채팅 원문과 연결되는 기록은 근거 메시지로 돌아갈 수 있어야 합니다.
- AI가 정리한 기록과 학생이 확정한 기록을 구분해야 합니다.
- 학생별 역할, 역할에 따른 할 일과 수행 과정이 연결되어 표시되어야 합니다.
- AI가 제안한 기록은 확인 대기 상태로 보여주고 학생 확인 후 확정 상태로 전환해야 합니다.

## 접근성·반응형 요구사항 초안

- 태블릿에서 채팅 입력과 메시지 읽기에 필요한 최소 너비를 보장해야 합니다.
- 화면이 좁으면 양쪽 영역을 접거나 탭·서랍 형태로 전환할 수 있어야 합니다.
- 화면 확대 시 핵심 기능이 가려지거나 접근 불가능해지지 않아야 합니다.
- 키보드 초점 순서와 화면 읽기 순서는 왼쪽, 중앙, 오른쪽의 시각적 구조와 모순되지 않아야 합니다.

## 미확정 요구사항

- 영역별 기본 너비와 크기 조절 허용 여부
- 태블릿 가로·세로 방향 지원 범위
- 보고서와 슬라이드 편집 화면 전환 방식
- 교사용 화면 구조
