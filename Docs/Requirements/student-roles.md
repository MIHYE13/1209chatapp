# 학생 역할 요구사항

## 확정 역할 명칭

- 이끄미
- 기록이
- 나누미
- 지키미

## 확정 요구사항

- 오른쪽 작업 영역에서 각 학생의 이름 또는 표시 이름과 역할을 함께 보여줘야 합니다.
- 역할에 따른 할 일과 수행 과정을 연결해 보여줘야 합니다.
- 역할은 채팅 발언 순서나 기본 채팅 권한을 제한해서는 안 됩니다.
- 모든 학생은 역할과 관계없이 채팅, 링크·파일 공유와 AI 도움 요청에 참여할 수 있어야 합니다.
- 모둠원이 4명보다 적어도 활동을 시작하고 계속할 수 있어야 합니다.
- 미참석 학생과 현재 참여 중인 학생을 구분할 수 있어야 합니다.
- 참여자 수와 배정된 역할 수가 다를 수 있다는 전제로 데이터를 구성해야 합니다.

## 미확정 요구사항

- 인원 부족 시 역할 겸임 또는 미배정 방식
- 최초 역할 배정 주체와 절차
- 활동 중 역할 교체 방식
- 이끄미, 기록이, 나누미, 지키미의 구체적인 책임
- 역할별 작업 기록의 기본 템플릿
