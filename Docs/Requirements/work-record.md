# 모둠 작업 기록 요구사항

## 목적

실시간 채팅은 빠르게 흘러가므로 중요한 역할, 할 일, 결정과 자료가 묻히지 않도록 오른쪽 영역에 구조화된 작업 기록을 축적합니다.

## 확정 요구사항

- 오른쪽 영역은 모둠의 진행 중 작업 내용을 계속 보여줘야 합니다.
- 기록은 중앙 채팅의 관련 메시지 또는 공유 자료와 연결될 수 있어야 합니다.
- 기록에는 내용, 유형, 작성 또는 추출 주체와 시각을 남겨야 합니다.
- AI가 만든 기록과 학생이 확정한 기록을 구분해서 표시해야 합니다.
- 같은 모둠원에게 기록의 추가·수정 상태가 실시간으로 동기화되어야 합니다.
- 교사는 모둠방을 열람할 때 오른쪽 작업 기록도 확인할 수 있어야 합니다.
- AI가 만든 초안은 학생의 확인 없이 확정 기록에 반영되어서는 안 됩니다.
- 학생은 AI 초안을 수락, 수정 또는 거절할 수 있어야 합니다.

## 역할 기반 기록 구조

오른쪽 영역은 학생별 역할과 작업 과정을 다음 정보로 보여줘야 합니다.

- 담당 학생 또는 표시 이름
- 역할: 이끄미, 기록이, 나누미 또는 지키미
- 역할에 따른 할 일
- 진행 상태
- 수행 과정과 중간 기록
- 관련 메시지, 링크 또는 파일
- 마지막 변경 시각

역할, 할 일과 수행 과정은 서로 연결되어야 하며 학생별로 현재 무엇을 하고 있는지 파악할 수 있어야 합니다.

역할은 작업 책임을 나타낼 뿐 채팅 순서나 발언 권한을 제한하지 않습니다. 모둠원이 4명보다 적은 상황에서도 작업 기록이 동작해야 합니다.

## AI 초안 반영 흐름

1. AI가 채팅에서 역할, 할 일 또는 과정 기록 후보를 찾습니다.
2. AI가 근거 메시지와 함께 구조화된 초안을 제안합니다.
3. 학생이 초안을 확인하고 필요하면 수정합니다.
4. 학생이 확인한 항목만 오른쪽 영역에 확정 반영합니다.
5. 반영 결과를 같은 모둠원의 화면에 실시간으로 동기화합니다.

## 기록 유형 후보

- 현재 탐구 단계
- 역할 분담
- 해야 할 일과 완료 상태
- 모둠 결정사항
- 탐구 질문과 예상
- 수집 자료와 근거
- 관찰·실험 내용
- 중간 결론과 남은 질문

## 미확정 요구사항

- 학생의 직접 편집과 삭제 권한
- AI 초안을 확정할 수 있는 학생의 범위
- 기록 변경 이력과 복구 범위
- 보고서·슬라이드로 전환할 기록의 선택 방식
