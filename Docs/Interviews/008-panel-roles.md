# 인터뷰 008: 3분할 영역별 역할

- 날짜: 2026-11-25
- 단계: 화면 설계 및 핵심 흐름

## 사용자 답변

- 왼쪽은 학습 관련 주제 등 교사가 관리하는 화면입니다.
- 중앙은 실시간 채팅 내용이 흘러가는 장면을 보여줍니다.
- 오른쪽은 모둠의 작업 내용이 진행 중간마다 기록되어 보입니다.

## 반영 내용

- 왼쪽 영역은 교사가 작성·관리하고 학생이 확인하는 학습 안내 영역입니다.
- 중앙 영역은 학생과 AI 보조교사의 실시간 메시지 흐름을 보여주는 모둠 채팅방입니다.
- 오른쪽 영역은 채팅에서 나온 역할, 할 일, 결정, 자료와 진행 내용을 구조화하여 축적하는 작업 기록 영역입니다.
- 세 영역을 동시에 보여 주어 학생이 학습 목표, 현재 대화와 누적 결과를 한 화면에서 연결해 이해하게 합니다.

## 남은 질문

- 오른쪽 기록을 AI가 자동으로 추가할지 학생 확인 후 반영할지
- 학생이 오른쪽 기록을 직접 편집할 수 있는지
- 기록 항목의 종류와 표시 순서
- 교사가 왼쪽 내용을 수업 중 수정했을 때 학생 화면에 반영하는 방식
