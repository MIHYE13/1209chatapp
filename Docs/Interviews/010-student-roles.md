# 인터뷰 010: 학생 역할과 모둠 인원 변동

- 날짜: 2026-11-25
- 단계: 역할·권한 및 핵심 흐름

## 사용자 답변

- 학생 4명의 역할 명칭은 이끄미, 기록이, 나누미, 지키미입니다.
- 모둠원 4명이 모두 모일 수도 있고 인원이 부족할 수도 있습니다.
- 역할은 대화 흐름과 상관이 없습니다.

## 반영 내용

- 네 역할의 공식 표시 명칭을 이끄미, 기록이, 나누미, 지키미로 사용합니다.
- 역할은 작업 책임과 과정을 정리하기 위한 정보입니다.
- 특정 역할만 먼저 말하거나 특정 기능을 사용하도록 채팅을 제한하지 않습니다.
- 결석이나 인원 변동이 있어도 모둠 채팅과 작업은 계속할 수 있어야 합니다.

## 남은 질문

- 모둠원이 부족할 때 한 학생이 여러 역할을 맡을지 역할을 비워둘지
- 역할을 교사가 지정할지 학생들이 정할지
- 활동 중 역할 변경을 허용할지
- 각 역할의 구체적인 책임과 완료 기준
