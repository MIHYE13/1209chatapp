# 인터뷰 006: 교사의 개입 범위

- 날짜: 2026-11-25
- 단계: 역할·권한

## 사용자 답변

교사는 채팅방의 관리자이지만 직접 개입하지 않습니다.

## 반영 내용

- 교사는 활동과 모둠방의 운영 관리자입니다.
- 교사는 모든 모둠방의 진행 상황과 채팅 자료를 실시간으로 열람합니다.
- 교사는 학생 모둠 채팅에 참여하거나 진행 방향을 직접 지시하지 않습니다.
- 교사의 관리 권한과 채팅 발언 권한을 분리합니다.

## 남은 질문

- 부적절하거나 위험한 메시지·파일에 대한 숨김 또는 차단 권한
- 교사의 결과물 피드백과 평가 기능
- 교사가 활동 시작·종료와 제출 상태를 관리하는 범위
