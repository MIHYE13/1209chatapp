# 인터뷰 001: 핵심 사용자

- 날짜: 2026-11-25
- 단계: 사용 맥락

## 질문

웹앱의 주 대상 학년은 누구인가?

## 사용자 답변

초등학교 5~6학년

## 반영 내용

- 학생용 문구는 짧고 구체적이며 행동 중심으로 작성합니다.
- 복잡한 과정을 작은 단계로 나누고 현재 단계와 다음 행동을 명확히 보여줍니다.
- AI의 제안을 정답처럼 제시하지 않고 학생이 검토하고 선택하게 합니다.
- 검색 자료의 출처와 신뢰도를 학생이 이해할 수 있는 방식으로 안내합니다.
- 교사 통제, 아동 개인정보 최소 수집과 안전한 협업을 주요 설계 제약으로 다룹니다.

## 남은 질문

- 정규 수업, 방과 후 또는 가정 과제 중 어느 환경에서 사용하는가?
- 학생이 사용하는 기기와 계정 환경은 무엇인가?
- 교사가 모둠 과정에 어느 정도 개입하는가?
