# 인터뷰 007: 3분할 화면 구조

- 날짜: 2026-11-25
- 단계: 화면 설계

## 사용자 답변

웹앱은 왼쪽, 중앙, 오른쪽의 3분할 구조이며 중앙에 모둠 채팅방이 열립니다.

## 반영 내용

- 모둠 활동의 기본 작업 화면은 3개의 세로 영역으로 구성합니다.
- 중앙 영역은 모둠 실시간 채팅과 AI 보조교사 대화를 위한 핵심 영역입니다.
- 왼쪽과 오른쪽 영역은 채팅 중에도 작업 흐름과 자료를 함께 볼 수 있도록 구성합니다.
- 실제 너비, 접기 동작과 좁은 화면 대응은 태블릿 환경을 확인한 뒤 결정합니다.

## 남은 질문

- 왼쪽 영역의 역할과 표시 정보
- 오른쪽 영역의 역할과 표시 정보
- 태블릿 방향과 최소 화면 크기
- 교사용 관리자 화면에도 같은 3분할 구조를 적용할지
- 보고서·슬라이드 편집 시 중앙 영역을 전환할지 별도 화면을 사용할지
