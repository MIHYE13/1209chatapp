# 인터뷰 011: 교사 설정 활동 타이머

- 날짜: 2026-11-25
- 단계: 핵심 흐름 및 교사 관리

## 사용자 답변

- 타이머 기능이 필요합니다.
- 교사가 설정한 시간 내에 채팅이 이루어집니다.
- 설정 시간이 지나면 채팅방은 멈춥니다.

## 반영 내용

- 교사는 활동 시작 전에 채팅 가능 시간을 설정합니다.
- 학생과 교사는 모든 기기에서 동일한 남은 시간을 확인합니다.
- 종료 판정은 개별 태블릿 시간이 아니라 서버 시간을 기준으로 합니다.
- 시간이 종료되면 새 학생 메시지와 AI 채팅을 서버에서 차단합니다.
- 종료 직전에 작성한 메시지의 처리와 종료 후 열람·수정 범위는 별도로 결정합니다.

## 남은 질문

- 종료 후 기존 채팅과 오른쪽 작업 기록을 열람할 수 있는지
- 종료 후 작업 기록과 결과물 수정도 막을지
- 교사가 시간을 연장·일시정지·재개할 수 있는지
- 종료 직전에 전송 중인 메시지와 파일 처리 방식
- 종료 알림 시점과 방식
