# 인터뷰 014: 학습 과정 데이터 축적

- 날짜: 2026-11-25
- 단계: 데이터·교사 관리 및 결과 분석

## 사용자 답변

- 학생 질문 데이터를 축적합니다.
- 전체 학생의 의견 수렴 과정 데이터를 축적합니다.
- 역할 분담 등의 과정 데이터를 축적합니다.

## 반영 내용

- 채팅 원문과 별도로 학생 질문을 구조화해 기록합니다.
- 모둠과 학급의 의견이 제안, 비교, 선택, 합의되는 과정을 기록합니다.
- 학생별 역할 배정, 변경, 할 일과 수행 과정을 기록합니다.
- 교사는 담당 활동에서 축적된 학습 과정을 확인할 수 있습니다.
- AI가 분류·요약한 데이터와 학생이 직접 확정한 데이터를 구분합니다.

## 남은 질문

- 데이터를 수업 개선, 학생 피드백 또는 평가 중 어디에 사용할지
- 전체 학생 의견 수렴을 투표, 선택, 합의 또는 서술형으로 진행할지
- 학생 개인별 기록과 모둠별 기록의 공개 범위
- 데이터 보관 기간과 삭제·내보내기 정책
- AI 분석 결과를 학생에게도 보여줄지
