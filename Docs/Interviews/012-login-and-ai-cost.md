# 인터뷰 012: 학생 등록과 AI 토큰 절약

- 날짜: 2026-11-25
- 단계: 인증 및 AI 도우미

## 사용자 답변

- OpenAI API 토큰을 최소화하여 구현합니다.
- 학생 등록 화면에서 학급, 이름, 모둠을 등록하고 로그인합니다.
- 모둠은 1모둠부터 6모둠까지입니다.

## 반영 내용

- 학생 등록 정보의 기본 필드는 학급, 이름, 모둠입니다.
- 학생은 등록 후 로그인하여 지정한 모둠방에 입장합니다.
- 모둠 값은 1~6 범위에서 선택합니다.
- OpenAI API는 백엔드에서만 호출합니다.
- 전체 대화를 반복 전송하지 않고 최근 대화와 누적 작업 요약을 조합합니다.
- AI 호출 시점, 문맥 길이와 응답 길이에 상한을 둡니다.

## 남은 질문

- 같은 학급에 동명이인이 있을 때 본인을 구분하는 방법
- 학생 비밀번호 또는 교사 발급 PIN 사용 여부
- 학급을 직접 입력할지 교사가 만든 목록에서 선택할지
- 학생이 모둠을 직접 선택할지 교사가 사전에 지정할지
- AI를 학생 요청 시 호출할지 작업 단계별로 호출할지
