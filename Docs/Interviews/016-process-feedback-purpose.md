# 인터뷰 016: 학습 과정 데이터 활용 목적

- 날짜: 2026-11-25
- 단계: 데이터 활용 및 피드백

## 사용자 답변

축적된 학습 과정 데이터는 학생과 모둠에 과정 중심 피드백을 제공하는 데 사용합니다.

## 반영 내용

- 질문, 의견 수렴, 역할 분담과 수행 과정 기록을 피드백의 근거로 사용합니다.
- 피드백은 최종 결과의 점수보다 학생이 어떻게 참여하고 협력했는지를 돌아보게 합니다.
- 개인 피드백과 모둠 피드백을 구분합니다.
- 메시지 수나 발언량만으로 참여 수준을 판정하지 않습니다.
- 평가·성적 반영은 별도 결정 전까지 범위에 포함하지 않습니다.

## 남은 질문

- AI가 피드백 초안을 만들고 교사가 확인할지, 교사가 직접 작성할지
- 수업 중간 또는 종료 후 언제 피드백을 제공할지
- 학생 개인에게만 보여줄 내용과 모둠 전체에 보여줄 내용
- 학생이 피드백에 응답하거나 성찰 기록을 남길지
- 피드백 보관 기간과 내보내기 방식
