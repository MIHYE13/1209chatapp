# 인터뷰 005: 교사 관리자 권한

- 날짜: 2026-11-25
- 단계: 역할·권한

## 사용자 답변

교사는 관리자가 되어 모든 실시간 채팅방의 채팅 자료를 확인할 수 있어야 합니다.

## 반영 내용

- 교사는 자신이 관리하는 활동의 모든 모둠방을 확인할 수 있습니다.
- 교사는 각 방의 학생 메시지, AI 응답, 공유 링크와 첨부 파일을 실시간으로 확인할 수 있습니다.
- 학생에게 교사가 활동 내용을 확인할 수 있다는 사실을 명확하게 안내해야 합니다.
- 교사 권한은 학생·모둠 권한과 분리하고 서버에서 검증해야 합니다.

## 남은 질문

- 교사가 모둠 채팅에 메시지를 보내거나 활동에 직접 개입할 수 있는지
- 교사가 메시지나 파일을 숨김·삭제할 수 있는지
- 전체 모둠 현황 화면에서 우선 보여줄 정보
- 수업 종료 후 채팅 기록의 열람 기간
- 교사가 결과물에 피드백이나 평가를 남길지
