# 인터뷰 002: 교실 운영 흐름

- 날짜: 2026-11-25
- 단계: 사용 맥락 및 핵심 흐름

## 사용자 답변

1. 교사가 주제와 할 일 등의 워크플로를 제시합니다.
2. 모둠별 학생이 접속해 모둠방 채팅으로 할 일을 구조화합니다.
3. 완성된 결과물을 공유합니다.
4. 학생들은 같은 와이파이에서 각자의 태블릿으로 접속합니다.

## 해석

- 초안 기준 한 모둠은 학생 4명으로 구성됩니다.
- 각 모둠은 다른 모둠과 분리된 하나의 실시간 협업방을 사용합니다.
- 교사가 활동을 만들면 모둠방들이 해당 활동의 주제와 단계 정보를 받습니다.
- 채팅은 단순 대화뿐 아니라 역할, 할 일, 결정과 결과물을 구조화하는 입력 수단입니다.
- 최종 결과물은 교사 또는 학급에 공유할 수 있어야 합니다.
- 같은 와이파이는 운영 조건이지만, 서버를 교실 내부에 둘지 인터넷 서비스로 둘지는 아직 결정하지 않았습니다.

## 남은 질문

- 학생이 모둠방에 입장하는 방식과 필요한 신원 확인 수준
- 교사가 실시간 채팅을 볼 수 있는 범위와 시점
- 결과물의 종류와 공유 대상
- 수업 종료 후 다시 접속하거나 수정할 필요가 있는지 여부
