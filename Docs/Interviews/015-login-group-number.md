# 인터뷰 015: 로그인 시 모둠 번호 확인

- 날짜: 2026-11-25
- 단계: 인증 및 교실 운영

## 사용자 답변

학생은 활동 코드, 이름과 모둠 번호를 입력해 로그인합니다.

## 반영 내용

- 로그인 화면에서 활동 코드, 학생 이름과 1~6 중 모둠 번호를 입력합니다.
- 서버는 세 값이 등록 정보와 일치하는지 확인합니다.
- 모둠 번호는 동명이인 구분과 잘못된 방 입장 방지에 사용합니다.
- 입력된 모둠 번호 자체로 권한을 부여하지 않고 등록된 배정 정보와 대조합니다.

## 남은 질문

- 같은 모둠 안에 동명이인이 있는 예외 상황 처리
- 로그인 실패 안내 문구와 재시도 제한
- 학생이 자신의 모둠 번호를 모를 때 교사에게 확인하는 흐름
