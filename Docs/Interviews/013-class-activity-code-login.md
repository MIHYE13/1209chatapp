# 인터뷰 013: 학급 공통 활동 코드 로그인

- 날짜: 2026-11-25
- 단계: 인증 및 교실 운영

## 사용자 답변

학생은 학급 공통 활동 코드와 이름을 함께 입력해 로그인합니다.

## 반영 내용

- 교사는 활동마다 학급 학생에게 공유할 공통 활동 코드를 발급합니다.
- 학생은 로그인 화면에서 활동 코드와 등록된 이름을 입력합니다.
- 서버는 활동 코드의 유효성과 등록 명단을 확인합니다.
- 확인된 학생은 등록된 모둠 정보에 따라 1~6모둠 중 자신의 모둠방으로 이동합니다.
- 학생이 로그인 화면에서 모둠을 다시 선택해 권한을 바꾸지 않도록 합니다.

## 남은 질문

- 같은 학급의 동명이인 구분 방식
- 활동 코드의 길이, 문자 구성과 만료 시점
- 코드가 외부에 알려졌을 때 교사의 재발급·차단 방식
- 한 학생의 중복 접속 허용 범위
- 이름 오타와 등록되지 않은 학생의 처리 방식
