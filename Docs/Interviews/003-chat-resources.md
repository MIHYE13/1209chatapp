# 인터뷰 003: 채팅방 자료 공유

- 날짜: 2026-11-25
- 단계: 핵심 흐름 및 검색·자료

## 사용자 답변

채팅방에서 링크 공유와 파일 공유가 가능해야 합니다.

## 반영 내용

- 학생은 모둠 채팅에 URL을 메시지로 전송할 수 있어야 합니다.
- 학생은 허용된 파일을 채팅 메시지에 첨부할 수 있어야 합니다.
- 같은 모둠원은 공유된 링크와 파일을 실시간으로 확인할 수 있어야 합니다.
- 공유된 링크와 파일은 이후 탐구 자료, 보고서와 발표자료에서 다시 사용할 수 있어야 합니다.

## 남은 질문

- 허용할 파일 형식과 파일당 용량
- 링크 미리보기와 외부 사이트 이동 경고 방식
- 파일 보관 기간과 삭제 권한
- 교사 열람, 신고와 차단 방식
- 공유 파일의 출처·저작권 정보 입력 방식
