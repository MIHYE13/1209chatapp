# 결정 017: 활동 코드·이름·모둠 번호 로그인

- 날짜: 2026-11-25
- 상태: 확정

## 결정

학생 로그인 정보는 다음 세 항목으로 구성합니다.

- 학급 공통 활동 코드
- 등록된 학생 이름
- 등록된 모둠 번호: 1~6

## 검증 방식

- 백엔드는 활동 코드가 활성 상태인지 확인합니다.
- 백엔드는 이름과 모둠 번호의 조합이 해당 활동의 등록 명단과 일치하는지 확인합니다.
- 사용자가 입력한 모둠 번호만으로 접근 권한을 부여하지 않습니다.
- 검증된 등록 정보에 저장된 모둠 식별자를 사용해 모둠방에 연결합니다.

## 제한

이 방식은 교실에서 빠르게 접속하기 위한 간편 식별 방식입니다. 같은 모둠에 이름이 같은 학생이 있거나 다른 학생이 세 정보를 모두 알고 있는 상황까지 강하게 방지하지는 못합니다.
