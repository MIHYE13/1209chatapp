# 결정 001: 핵심 사용자

- 날짜: 2026-11-25
- 상태: 확정
- 결정: 웹앱의 핵심 사용자를 초등학교 5~6학년 학생으로 정합니다.

## 이유

사용자가 대상 학년을 초등학교 5~6학년으로 지정했습니다.

## 영향

- 화면, 문장, 과제 단계와 오류 안내의 인지 부담을 낮춥니다.
- AI 도우미는 답을 대신 작성하기보다 질문, 역할 분담과 근거 확인을 돕습니다.
- 아동 개인정보, 부적절한 콘텐츠, 외부 웹 접근과 교사 감독을 핵심 안전 요구사항으로 다룹니다.
- 보고서와 발표자료 구조는 초등학교 5~6학년 교육과정 및 실제 평가 양식을 확인한 뒤 확정합니다.
