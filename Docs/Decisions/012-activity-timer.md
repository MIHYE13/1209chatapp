# 결정 012: 교사 설정 활동 타이머

- 날짜: 2026-11-25
- 상태: 확정

## 결정

교사는 활동별 채팅 가능 시간을 설정합니다. 설정된 시간이 끝나면 해당 활동의 모든 모둠방에서 실시간 채팅을 중단합니다.

## 기본 동작

1. 교사가 활동 시간을 설정합니다.
2. 활동 시작과 함께 서버 기준 종료 시각을 확정합니다.
3. 학생과 교사 화면에 동일한 남은 시간을 표시합니다.
4. 종료 시각이 되면 새 학생 메시지와 AI 채팅 요청을 서버에서 거부합니다.
5. 학생 화면은 채팅이 종료되었다는 상태와 이유를 명확히 표시합니다.

## 영향

- 타이머는 브라우저 화면뿐 아니라 백엔드에서 강제해야 합니다.
- 태블릿이 잠시 끊겼다가 재접속해도 서버 종료 시각을 기준으로 남은 시간을 복원해야 합니다.
- 교사가 여러 모둠을 관리하더라도 같은 활동의 종료 상태가 일관되어야 합니다.
- 메시지, 파일 업로드와 AI 요청 각각에 종료 상태 검사가 필요합니다.
- 종료 후 열람·기록 수정·결과물 제출 범위는 후속 결정이 필요합니다.
