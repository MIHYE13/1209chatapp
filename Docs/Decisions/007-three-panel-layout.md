# 결정 007: 모둠 활동 화면의 3분할 구조

- 날짜: 2026-11-25
- 상태: 확정

## 결정

학생용 모둠 활동 화면은 왼쪽, 중앙, 오른쪽의 3분할 구조를 기본으로 합니다. 중앙 영역에는 모둠의 실시간 채팅방을 배치합니다.

## 영향

- 채팅을 유지한 채 작업 단계, 자료 또는 결과물을 다른 영역에서 확인할 수 있어야 합니다.
- 각 영역은 독립적인 스크롤과 명확한 제목을 가져야 합니다.
- 중앙 채팅 영역은 메시지 읽기와 입력에 충분한 너비를 확보해야 합니다.
- 태블릿 화면 크기와 방향에 따라 양쪽 영역을 접거나 전환하는 반응형 동작이 필요할 수 있습니다.
- 키보드 탐색과 보조기술에서 영역 순서와 초점 이동이 명확해야 합니다.
