# 결정 014: 학생 등록과 로그인 정보

- 날짜: 2026-11-25
- 상태: 부분 확정

## 확정된 결정

학생은 등록 화면에서 다음 정보를 등록한 뒤 로그인합니다.

- 학급
- 이름
- 모둠: 1모둠, 2모둠, 3모둠, 4모둠, 5모둠 또는 6모둠

로그인한 학생은 자신의 모둠방으로 이동합니다.

## 미확정 결정

- 동명이인 구분 방식
- 학급 생성과 선택 방식
- 모둠을 학생이 선택할지 교사가 지정할지
- 등록 정보 수정과 계정 복구 방식

이 항목들이 확정되기 전에는 학급·이름·모둠만으로 안전한 인증이 완성되었다고 간주하지 않습니다.

## 후속 확정

- 로그인 확인 수단은 `학급 공통 활동 코드 + 등록된 학생 이름`입니다.
