# 결정 003: 채팅방 링크·파일 공유

- 날짜: 2026-11-25
- 상태: 확정

## 결정

모둠 채팅방은 링크와 파일 공유를 지원합니다.

## 영향

- 실시간 메시지 구조에서 일반 메시지, 링크와 파일 첨부를 구분해야 합니다.
- 업로드 저장소, 접근 권한, 파일 크기·형식 제한과 삭제 정책이 필요합니다.
- 다른 모둠이 첨부 파일 주소를 알아도 열 수 없도록 서버 측 권한 검사가 필요합니다.
- 외부 링크와 파일은 유해 콘텐츠, 악성 파일, 개인정보와 저작권 위험을 고려해야 합니다.
- 공유 자료가 채팅에서 사라지지 않도록 별도의 자료 모음과 연결하는 방식을 검토합니다.
