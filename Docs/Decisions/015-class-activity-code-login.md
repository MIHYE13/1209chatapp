# 결정 015: 학급 공통 활동 코드와 이름 로그인

- 날짜: 2026-11-25
- 상태: 확정

## 결정

학생은 교사가 안내한 학급 공통 활동 코드, 등록된 학생 이름과 모둠 번호를 함께 입력하여 로그인합니다.

## 로그인 흐름

1. 교사가 활동을 만들고 학급 공통 활동 코드를 발급합니다.
2. 학생 등록 정보에는 학급, 이름과 1~6 중 소속 모둠을 저장합니다.
3. 학생은 로그인 화면에서 활동 코드, 이름과 모둠 번호를 입력합니다.
4. 백엔드가 코드의 유효성과 활동에 등록된 이름·모둠 조합을 확인합니다.
5. 백엔드에 저장된 모둠 정보를 기준으로 해당 모둠방에 연결합니다.

## 보안 수준

이 방식은 초등학교 교실에서 빠르게 입장하기 위한 간편 식별 방식이며 강한 본인 인증은 아닙니다. 활동 코드를 아는 사람이 다른 학생 이름을 입력할 가능성을 완전히 차단하지 못합니다.

따라서 다음 보완이 필요합니다.

- 추측하기 어려운 활동 코드 생성
- 활동 시작·종료에 따른 코드 활성화와 만료
- 반복 로그인 실패 제한
- 교사의 현재 접속 학생 확인
- 다른 모둠 권한을 요청해도 서버에서 차단
- 동명이인 처리 방식 확정
