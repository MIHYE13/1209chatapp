# 결정 013: OpenAI API 토큰 최소화

- 날짜: 2026-11-25
- 상태: 확정

## 결정

생성형 AI 보조교사는 OpenAI API를 사용하되 입력·출력 토큰과 불필요한 호출을 최소화하도록 설계합니다.

## 적용 원칙

- OpenAI API 키는 백엔드 환경변수에만 저장합니다.
- 학생 메시지마다 AI를 자동 호출하지 않습니다.
- 매 호출에 전체 채팅 기록을 전달하지 않습니다.
- 최근 대화 일부, 교사의 현재 활동 단계와 구조화된 누적 요약만 전달합니다.
- 역할, 할 일, 결정과 진행 과정은 자유 형식 대화보다 간결한 구조 데이터로 유지합니다.
- 질문과 관련 없는 링크 원문, 파일 전체 내용과 오래된 대화를 제외합니다.
- 응답 길이와 생성 항목 수에 상한을 둡니다.
- 동일한 작업을 짧은 시간에 중복 호출하지 않도록 요청 상태를 관리합니다.
- 활동·모둠별 토큰 사용량과 호출 횟수를 서버에서 측정합니다.
- 비용 절감을 위해 학생 개인정보나 대화를 임의로 공용 캐시에 공유하지 않습니다.

## 권장 문맥 구성

1. 교사가 설정한 탐구 주제와 현재 단계
2. 모둠의 확정된 역할·할 일·결정 요약
3. 아직 해결하지 못한 질문
4. 최근 관련 대화 일부
5. 학생이 현재 요청한 작업

## 영향

- 대화 요약을 갱신하고 버전 관리하는 백엔드 기능이 필요합니다.
- 요약이 원문과 달라지지 않도록 학생이 확정한 기록을 우선 문맥으로 사용해야 합니다.
- AI 호출 실패가 채팅 자체를 중단시키지 않도록 채팅과 AI 처리를 분리해야 합니다.
