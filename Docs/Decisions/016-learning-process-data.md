# 결정 016: 학생 학습 과정 데이터 축적

- 날짜: 2026-11-25
- 상태: 확정

## 결정

웹앱은 최종 결과물뿐 아니라 학생 질문, 전체 학생의 의견 수렴 과정, 역할 분담과 수행 과정을 구조화된 학습 과정 데이터로 축적합니다.

## 축적 대상

- 학생이 제기한 질문과 질문 시각
- 질문이 연결된 탐구 단계, 메시지와 자료
- 학생·모둠이 제시한 의견
- 의견의 비교, 수정, 선택과 합의 과정
- 역할 배정과 변경 이력
- 역할에 따른 할 일, 진행 상태와 수행 과정
- AI가 제안한 초안과 학생의 수락·수정·거절 결과

## 원칙

- 학생이 직접 작성·확정한 내용과 AI가 추출·요약한 내용을 구분합니다.
- 채팅 원문과 구조화된 과정 데이터 사이의 근거 연결을 유지합니다.
- 학생 활동을 단순 메시지 수나 AI 분석만으로 평가하지 않습니다.
- 데이터는 학생·모둠의 과정 중심 피드백에 사용합니다.
- 성적 또는 공식 평가 활용은 별도 승인 전까지 범위에 포함하지 않습니다.
- 담당 교사와 해당 학생·모둠의 접근 범위를 역할에 따라 제한합니다.

## 영향

- 질문, 의견, 결정, 역할과 작업 기록을 별도 데이터 유형으로 관리해야 합니다.
- 시간 순서와 변경 이력을 보존해야 합니다.
- 교사용 화면에서 모둠별 과정과 학급 전체 경향을 구분해 보여줘야 합니다.
- 보관 기간, 삭제, 다운로드와 평가 활용 정책을 확정해야 합니다.
