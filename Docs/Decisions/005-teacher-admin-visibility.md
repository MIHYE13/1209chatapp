# 결정 005: 교사의 전체 모둠방 열람 권한

- 날짜: 2026-11-25
- 상태: 확정

## 결정

교사는 활동 관리자로서 자신이 관리하는 활동에 속한 모든 모둠방의 채팅 자료를 실시간으로 열람할 수 있습니다.

열람 대상에는 다음 항목이 포함됩니다.

- 학생 메시지
- 생성형 AI 보조교사의 메시지
- 공유된 링크
- 첨부 파일과 기본 정보
- 모둠의 작업 단계, 할 일과 결정사항

## 영향

- 교사용 전체 모둠 현황 화면과 모둠방 상세 화면이 필요합니다.
- 교사와 학생의 역할 기반 접근 제어가 필요합니다.
- 교사는 담당 활동의 자료만 볼 수 있어야 하며 다른 교사의 활동은 기본적으로 볼 수 없어야 합니다.
- 교사의 열람 가능 사실과 채팅 기록 처리 방식을 학생에게 안내해야 합니다.
- 열람 권한과 수정·삭제·개입 권한을 별도로 정의해야 합니다.
