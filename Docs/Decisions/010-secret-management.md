# 결정 010: 환경변수와 비밀정보 관리

- 날짜: 2026-11-25
- 상태: 확정

## 결정

실제 환경변수 값, API 키, 토큰, 서비스 계정 인증정보와 기타 비밀정보는 프로젝트 저장소와 GitHub에 공유하지 않습니다.

## 관리 원칙

- 로컬 개발 값은 Git에서 제외된 환경파일 또는 운영체제의 안전한 비밀 저장 방식으로 관리합니다.
- 배포 환경의 값은 배포 플랫폼이 제공하는 환경변수 또는 비밀 관리 기능에 저장합니다.
- 브라우저로 전달되는 프론트엔드 코드에는 서버 비밀키를 넣지 않습니다.
- 저장소에는 필요한 변수 이름과 용도만 담은 예시 파일을 둘 수 있습니다.
- 예시 값은 실제 키처럼 보이거나 실제 서비스에 연결될 수 있는 값을 사용하지 않습니다.
- 로그, 오류 메시지, 화면 캡처와 테스트 데이터에 비밀정보가 노출되지 않도록 합니다.

## 영향

- AI, 파일 저장소, 데이터베이스와 배포 서비스의 비밀키는 백엔드 또는 배포 환경에서만 사용해야 합니다.
- 환경별 설정 분리와 키 교체 절차를 기술 설계 단계에서 정의해야 합니다.
- 비밀정보가 커밋된 경우 파일 삭제만으로 끝내지 않고 해당 키를 즉시 폐기·교체해야 합니다.
