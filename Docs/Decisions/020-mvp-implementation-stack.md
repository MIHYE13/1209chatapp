# 결정 020: 교실 시연 MVP 구현 구조

- 날짜: 2026-11-25
- 상태: 구현 및 검증 완료

## 결정

1시간 교실 시연 MVP는 다음 구조로 구현합니다.

- 프론트엔드: Vanilla JavaScript, HTML, CSS
- 백엔드: Python FastAPI
- 실시간 채팅: FastAPI WebSocket
- 로컬 데이터베이스: SQLite
- 로컬 파일 저장: 백엔드 전용 업로드 디렉터리
- AI: 백엔드에서 OpenAI Responses API 호출

## 선택 이유

- 빌드 도구와 프레임워크 초기 설정을 줄여 제한 시간 안에 검증할 수 있습니다.
- 프론트엔드와 백엔드 책임은 폴더와 API 수준에서 분리합니다.
- API 키와 데이터 접근 권한을 브라우저에 노출하지 않습니다.
- SQLite로 로컬 수업 시연을 빠르게 검증하고 운영 확장 시 Firestore로 교체할 수 있습니다.

## 검증된 흐름

- 활동 코드·학급·이름·모둠 로그인
- 역할 자동 배정
- 같은 모둠의 WebSocket 메시지 동기화
- 다른 모둠 데이터 분리
- AI 다음 행동 제안
- 학생 확인 후 작업 기록 확정
- 교사의 모든 모둠 관찰
- AI 피드백 초안과 교사 공개
- 서버 타이머 판정
- 이미지·PDF 파일 업로드 제한

## 운영 전 필수 보강

- 학생 본인 인증과 교사 인증 강화
- Firestore 또는 운영 데이터베이스 연결
- 오브젝트 스토리지와 악성 파일 검사
- HTTPS와 배포 도메인 설정
- 데이터 보관·삭제·백업 정책
- 학교 와이파이와 실제 태블릿 동시 접속 부하 테스트
