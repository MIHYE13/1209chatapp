# 022. 교사 관리자 기능

- 상태: 확정 및 구현
- 날짜: 2026-11-25

## 결정

교사는 관찰자 역할을 유지하면서 등록 학생 확인, 학생의 모둠 변경, 개별·전체 학생 등록 초기화, 모둠별 대화·작업·피드백·첨부 파일 초기화를 수행할 수 있습니다.

## 안전 기준

- 학생 모둠을 변경하면 기존 모둠과 새 모둠의 역할을 인원 순서에 맞게 다시 배정합니다.
- 등록 초기화와 대화 초기화는 확인 대화상자를 거친 뒤 실행합니다.
- 학생 등록을 초기화해도 기존 학습 과정 자료는 유지합니다.
- 모둠 대화 초기화는 해당 모둠의 채팅, 작업 기록, 피드백과 첨부 파일만 삭제합니다.
- 모든 관리자 API는 교사 코드 검증을 요구합니다.

## 검증

`Tests/test_teacher_admin.py`의 독립 시험 활동으로 학생 이동, 개별 삭제, 대화 초기화와 전체 등록 초기화를 검증합니다.
