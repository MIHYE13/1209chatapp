# 결정 006: 교사의 관찰형 관리자 역할

- 날짜: 2026-11-25
- 상태: 확정

## 결정

교사는 활동과 모둠방의 관리자이지만 모둠의 학생 채팅이나 학습 진행에 직접 개입하지 않는 관찰형 관리자 역할을 가집니다.

## 허용되는 역할

- 활동과 모둠방 생성·운영
- 모든 모둠방의 채팅, AI 응답과 공유 자료 실시간 열람
- 모둠의 현재 단계와 결과물 공유 상태 확인

## 허용하지 않는 역할

- 학생 모둠 채팅에 일반 참여자로 메시지 전송
- 모둠의 토론이나 탐구 결론을 대신 결정
- 학생 대신 AI 제안을 수락하거나 결과물을 확정

안전사고 대응을 위한 콘텐츠 숨김·차단과 결과물 평가 권한은 별도 인터뷰 전까지 미확정으로 둡니다.
