# 결정 002: 기본 교실 워크플로

- 날짜: 2026-11-25
- 상태: 확정

## 결정

기본 활동 흐름을 다음과 같이 정합니다.

1. 교사가 탐구 주제와 수행할 단계 또는 할 일을 제시합니다.
2. 학생 4명이 각자 태블릿으로 모둠별 실시간 채팅방에 접속합니다.
3. 학생들은 채팅과 구조화 기능을 이용하여 역할, 할 일, 자료와 결론을 정리합니다.
4. 모둠이 결과물을 교사 또는 학급에 공유합니다.

초기 사용 환경은 같은 학교 와이파이입니다.

## 영향

- 활동, 모둠, 참여자와 결과물을 구분하는 데이터 구조가 필요합니다.
- 모둠별 메시지가 다른 모둠에 노출되지 않도록 방 단위 권한이 필요합니다.
- 여러 태블릿에 메시지와 구조화된 상태를 즉시 전파하는 실시간 통신이 필요합니다.
- 교사가 만든 활동 템플릿을 각 모둠방에 배포하는 흐름이 필요합니다.
- 결과물 공유 전 학생의 확인 단계와 공유 후 교사의 열람 흐름이 필요합니다.
