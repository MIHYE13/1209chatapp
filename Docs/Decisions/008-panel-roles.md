# 결정 008: 왼쪽·중앙·오른쪽 영역의 역할

- 날짜: 2026-11-25
- 상태: 확정

## 결정

학생용 모둠 활동 화면의 세 영역을 다음과 같이 구성합니다.

### 왼쪽: 교사 관리 학습 안내

- 탐구 주제
- 학습 목표
- 활동 단계와 할 일
- 교사가 제공한 안내와 자료

학생은 이 영역을 확인하되 교사가 관리하는 원본 내용을 임의로 변경하지 않습니다.

### 중앙: 실시간 모둠 채팅

- 학생 메시지
- 생성형 AI 보조교사 응답
- 공유 링크와 첨부 파일
- 새 메시지가 시간 순서대로 이어지는 실시간 대화 흐름

### 오른쪽: 모둠 작업 기록

- 역할과 할 일
- 모둠의 결정사항
- 수집한 자료와 근거
- 현재 진행 단계와 중간 결과

오른쪽 영역은 중앙 대화에서 생긴 중요한 작업 내용을 중간마다 구조화하여 누적해서 보여줍니다.

## 영향

- 교사 관리 정보와 학생 생성 정보를 데이터와 권한 수준에서 분리해야 합니다.
- 중앙의 일시적인 대화와 오른쪽의 지속적인 작업 기록을 연결하는 기능이 필요합니다.
- 채팅 메시지가 많아져도 오른쪽에서 핵심 작업 상태를 빠르게 파악할 수 있어야 합니다.
- 자동으로 추출된 기록은 AI 생성 내용임을 표시하고 확정 방식은 별도로 결정해야 합니다.
