# 결정 011: 학생 역할 명칭과 채팅 권한

- 날짜: 2026-11-25
- 상태: 확정

## 결정

모둠의 기본 역할 명칭을 다음 네 가지로 정합니다.

- 이끄미
- 기록이
- 나누미
- 지키미

역할은 모둠의 작업 책임을 구조화하고 오른쪽 작업 기록에 과정을 표시하기 위해 사용합니다. 역할에 따라 채팅 순서, 발언 횟수 또는 기본적인 채팅 권한을 제한하지 않습니다.

## 인원 변동

- 모둠원 4명이 모두 참석하지 않아도 모둠방을 사용할 수 있어야 합니다.
- 인원이 부족해도 채팅, 자료 공유, AI 도움과 작업 기록 기능이 중단되어서는 안 됩니다.
- 역할 겸임 또는 미배정 처리 방식은 후속 인터뷰에서 결정합니다.

## 영향

- 참여자 수와 역할 수를 항상 동일하다고 가정하면 안 됩니다.
- 학생 계정과 역할을 분리해 역할 변경이나 겸임 가능성을 지원해야 합니다.
- 오른쪽 작업 기록은 미참석 학생이나 미배정 역할을 명확히 표시할 수 있어야 합니다.
