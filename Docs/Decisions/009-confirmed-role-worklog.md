# 결정 009: 학생 확인 후 반영되는 역할 기반 작업 기록

- 날짜: 2026-11-25
- 상태: 확정

## 결정

오른쪽 모둠 작업 기록에는 AI가 만든 초안을 자동 확정하지 않습니다. 학생이 초안 내용을 확인한 후에만 작업 기록에 반영합니다.

오른쪽 작업 기록의 기본 단위에는 다음 정보가 포함됩니다.

- 학생 또는 표시 이름
- 모둠에서 맡은 역할
- 역할에 따라 수행할 일
- 현재 진행 상태
- 지금까지 수행한 과정
- 관련 채팅 메시지 또는 공유 자료
- 마지막 변경 시각

## 흐름

1. 학생들이 중앙 채팅에서 역할과 할 일을 논의합니다.
2. AI 보조교사가 대화에서 역할 기반 작업 기록 초안을 구성합니다.
3. 학생 화면에 초안과 근거가 된 대화를 함께 보여줍니다.
4. 학생이 수락하거나 내용을 수정합니다.
5. 확인된 내용만 오른쪽 작업 기록에 반영하고 모둠원에게 실시간 동기화합니다.

## 영향

- AI 제안 상태와 학생 확정 상태를 데이터에서 구분해야 합니다.
- 확정 전 초안은 결과물이나 교사 진행 현황에 확정 사실처럼 표시하면 안 됩니다.
- 학생은 AI 제안을 거절하거나 수정할 수 있어야 합니다.
- 기록 항목은 담당 학생, 역할, 할 일과 수행 과정의 관계를 유지해야 합니다.
